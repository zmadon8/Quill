# Edit mode: design mockups

Static pictures of the approved Edit redesign. The live app is not changed. The pages use the app's real `tokens.css` and `site.css`; the new styles for the mockups are only in `edit-mode.css` (so they can later move into `site.css`). Open the `.html` files in a browser, or look at the PNGs in `images/`. Each page has a viewport picture (`name.png`) and a whole-page picture (`name-full.png`).

Note: the machine that made the pictures has only one sans font, so serif text (program name, headings, item text) shows as sans in the PNGs. On a normal computer it shows in the real serif.

**1. Reading, Edit off (desktop)** (`1-reading-desktop`). The normal reading page. There is one clearly labelled Edit switch (pencil and the word "Edit") beside "All" on the directory bar. No other controls appear.

**2. Edit on (desktop)** (`2-edit-on-desktop`). The page has a faint blue-grey tint so it is obvious. The bar shows Undo and Done. Every row (Topic, Sub-topic, Section, Item, Nested Item) has just two small buttons at the right edge, "+ Add" and "Edit". Items, Nested Items and Sections have a drag grip at the left. Headings have none.

**3. Add form after an Item (desktop)** (`3-add-form-desktop`). "+ Add" on Item (2) opens a small form directly below it. Choose Item, Nested Item or Section, type the Text (with B, I, U), add a Citation, then Save or Cancel. The hint line shows the keyboard shortcuts.

**3b. Add form after a Sub-topic (desktop)** (`3b-add-form-subtopic-desktop`). The same form after the Sub-topic "2. General". The choices are "Item inside", "Sub-topic" and "Topic".

**4. Editing card on an Item (desktop)** (`4-edit-card-desktop`). "Edit" turns the Item into a card in place: text with B, I, U, a list of citations (each with an optional comment, a remove x and a drag grip), "+ another citation", the Flag choice (None, Overruled, Doubted, Other with short text), the For review switch with a note, and a bottom bar with Save, Cancel and "More". The More menu is shown open: Move to…, Move up, Move down, Change to Nested Item, History, and Delete in red with "goes to Trash · Undo available".

**5. Editing card on a heading (desktop)** (`5-heading-card-desktop`). A heading card has only the name and More (Move to…, History, Delete). A note says "Topics are sorted A–Z automatically". Headings have no grip.

**6. Edit on (phone)** (`6-edit-on-phone`). The same Edit view on a 390 px wide phone. The bar wraps onto two lines. Add and Edit become larger buttons (60 by 56 px) with the word under the icon, placed under each Item and at the right of each heading.

**7. Add form (phone)** (`7-add-form-phone`). The add form opens in place under the row, with 44 px buttons and a full-width Save and Cancel.

**8. Editing card (phone, full screen)** (`8-edit-card-phone`). On a phone the editing card fills the screen: Cancel and Save at the top, the fields in one column (each citation's comment sits under its citation), and Save, Cancel and More fixed at the bottom. The More menu opens upward.

Notes: the "See also" Note rows have no buttons because they are not edited this way. Sample content comes from the diary (Arbitration, Arbitrability, Fraud, General). The nested Item (Vidya Drolia), the "@ para 22" comment and the Ex Parte Item text are placeholders for layout only.
