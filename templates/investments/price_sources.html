Price sources

Prices are fetched by the nightly job (and the Update Prices button) with the standard library only. A refused or failed request is retried a few times, then that symbol keeps its last price and is marked old. Hand-entered and uploaded prices are never overwritten. Local helper: {% if helper_on %}on{% else %}off{% endif %}.

Bhavcopy

The exchanges' own daily files: NSE and BSE closing prices for shares and ETFs, and NSE's index closes (Nifty 50, Nifty Bank and others; not Sensex). One download a day covers every investment. They fill only the last 14 days of an investment that already has a price history, and never replace a price Yahoo fetched. A price from the Google Sheet is replaced by the exchange's official close.

{% csrf_token %}

"Before Yahoo" asks Yahoo only for what the files did not cover, so Yahoo is less likely to refuse; Yahoo's split and dividend reports are then seen only for those investments. If an investment is not found, set a symbol for the source bhavcopy on its catalogue page (the NSE symbol, for example RELIANCE, or for an index its name in NSE's file, for example Nifty 50).

Google Sheet

{% if helper_on %}Set up the Google Sheet{% endif %}

A Google Sheet can look prices up with GOOGLEFINANCE and send them here every evening. Its prices fill only days with no price yet; the nightly Yahoo and bhavcopy prices replace them. {% if not helper_on %}To use it, set PRICE_HELPER_ENABLED to 1 on the web service in Render (it uses the helper's token and address).{% endif %}
