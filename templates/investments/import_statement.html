Import a statement

A CSV or Excel file with a header row and one transaction per row. The columns are found by their headings, in any order:

  • Date of transaction, Transaction type (Buy or Sell), Transaction quantity and Transaction price (or the amount).
  • Investment code (NSE code such as RELIANCE.NS, AMFI scheme code, or ISIN) and Name of investment: a code the program knows uses that investment; any other is added from its name, code and Type (Share, Mutual Fund, Foreign, Alternative) when you save.
  • Portfolio, Broker and Folio on each row; a portfolio or broker you do not have yet is added. Charges, if the file has them.
  • Origin (optional): Purchase, Bonus, Split, Demerger or Other (a gift or transfer in). Bonus shares, split units, shares received on a demerger and other no-cost entries need no price. A row with units but no price is never taken as a purchase: choose what it is in the Treated as column below. You can set this for any row on the review page.
Words the Origin and Transaction type columns understand

Capitals, hyphens and extra spaces do not matter, and a cell that starts with one of the longer words (for example "Bonus shares 1:1") counts too. The Origin column is read first; if it is blank or not recognised, the Transaction type cell is tried. A line with no recognised word is a purchase, and needs a price. You can also choose how any line is treated on the review page.
