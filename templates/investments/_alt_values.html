Entries tagged From purchase or From sale are made automatically from your transactions. A value you enter yourself for the same date is kept and wins.

An alternative investment has no price feed. Add a value whenever you have one; a value you enter overrides the interest from its date, even with an interest rate set; {% if inst.interest_rate %}with an interest rate set, the value grows at the rate from your latest entry, so the Settings choice of averaged or unchanged between entries does not apply{% else %}between entries the value is {% if inv_settings.alt_treatment == "averaged" %}averaged out{% else %}held unchanged{% endif %} (Settings){% endif %}.

{% if not inst.lump_sum %}

For per-unit investments, enter a unit price and the value is worked out from the units you held on that date. It is not updated if you later buy or sell more units, so enter a total value or a new price then.
