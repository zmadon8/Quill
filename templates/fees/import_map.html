About memo numbers

  • A number that looks like 2025-26/12 is kept as an automatic number, if its year matches the memo date and nobody has used it. The next automatic number then continues after the highest one. Any other text (such as INV-5) is a custom number.
  • Numbering (optional column), per row: Auto gives the next automatic number and ignores any number in the file (it needs a valid date). Custom keeps the text exactly as a custom number, even if it looks automatic; that is only allowed for a past financial year. Draft imports the row as a draft with no number. Leave it blank to decide from the number column.
  • Order (optional column): a whole number, gaps allowed. Rows that get a new automatic number are numbered in this order within each financial year. Without it they are numbered by memo date, then by their place in the file.
